# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 9.5.x   | :white_check_mark: |
| < 9.5   | :x:                |

## Reporting a Vulnerability

If you discover a security issue in Neon District, please report it responsibly.

- Open a private GitHub Security Advisory if possible
- Or create a regular issue with the `security` label (avoid sharing exploit details publicly)

We will review and respond as quickly as possible.

This is a client-side single-file game. There is no backend, so most traditional server vulnerabilities do not apply. Still, any XSS or localStorage-related concerns are welcome.
